No. It is not OSI-approved because it restricts commercial use by third parties, which violates the Open Source Definition. This is intentional.

Only for non-commercial purposes. Internal use in production that contributes to revenue or operations is prohibited. Evaluation, testing, and development are permitted.

No, not unless you are the copyright holder. Third parties cannot sell or commercially exploit the software without explicit written permission.

Can I use WD-NCL for my own projects?
Yes. The license is provided as a template for anyone to use. Just replace the placeholders ([Year], [Copyright Holder Name], [Your Jurisdiction]) with your own details.

You can include a note in your README or documentation: "This project uses the whitedragon-dev Non-Commercial License (WD-NCL) v1.0." A link to the license documentation is appreciated.
