Open-source organization

Minimal software for the open web.

WhiteDragon-dev is an open-source organization that develops minimal software on Cloudflare Workers and Pages: an edge AI worker, a forwarding proxy, a multi-tab desktop browser, a community forum, and two source-available licenses. Each project uses few dependencies, requires no build step, and is small enough to be read in full.

Approach

Engineering principles

◆

Minimal by default

A single file is used wherever a single file is sufficient. There is no build pipeline, no framework, and no dependency tree requiring continual maintenance.

■

Edge-first

All projects target Cloudflare Workers and Pages. Deployment occurs on push, no servers require administration, and latency remains low across regions.

▲

Open, project by project

Source code is available to read, run and study. Licensing is determined per repository and stated there; no project is covered by association.

$wrangler deploy

Deployed. No build step, no server to manage.

Every project ships the same way: wrangler deploy, and it's live.
